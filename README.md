# Home Assistant Apps

A small Home Assistant app repository using pinned upstream container images.

Included apps:

- **Trilium Notes** — TriliumNext
- **Mealie** — recipe manager
- **Flame Dashboard** — Flame instance
- **Flame Dashboard 2** — second Flame instance

## Privacy

This repository contains only app definitions and small startup wrappers.

User-specific configuration is kept in Home Assistant and must not be committed
to this repository. In particular, do not commit databases, backups,
`options.json`, passwords, API keys, private domains, internal hostnames, IP
addresses, or certificates.
